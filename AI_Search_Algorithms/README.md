# AI Search Algorithms - Performance Evaluation

## Project Title
**Evaluate the Performance of Various Algorithms (Uninformed, Informed, Local Search and Constraint Satisfaction) for Problem Solving Through Search**

## Algorithms Implemented

### Uninformed Search
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Uniform Cost Search (UCS)

### Informed Search
- Greedy Best First Search
- A* Search using Manhattan Distance

### Local Search
- Hill Climbing
- Simulated Annealing

### Constraint Satisfaction
- Backtracking
- Forward Checking

## Problems

### 8-Puzzle
Used for BFS, DFS, UCS, Greedy Best First Search and A*.

Initial state:
```text
1 2 3
4 0 6
7 5 8
```

Goal state:
```text
1 2 3
4 5 6
7 8 0
```

### 8-Queens
Used for Hill Climbing, Simulated Annealing, Backtracking and Forward Checking.

## Performance Metrics

The program measures:
- Execution time
- Nodes explored
- Nodes generated
- Path length
- Path cost
- Iterations
- Final conflicts
- CSP assignments
- CSP backtracks

## How to Run

### 1. Install Python
Python 3.9+ is recommended.

### 2. Install matplotlib
```bash
pip install matplotlib
```

### 3. Run
```bash
python main.py
```

The program automatically creates:
- `outputs/complete_output.txt`
- `results/performance_results.csv`
- graphs in the `graphs/` directory
